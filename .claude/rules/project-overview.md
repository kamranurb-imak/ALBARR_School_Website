# Project Overview

**Al-Barr Secondary School** — static 7-page school website. Pure HTML/CSS/JS, no build step, no framework, no package manager.

## Running locally

```
start chrome index.html          # Windows
python -m http.server 8080       # optional local server (Python 3)
```
